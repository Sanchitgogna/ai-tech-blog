Alibaba

17 November 2026

Alibaba's Qwen4-Max is 62% cheaper per task. The independent maths says: not quite.

Alibaba released Qwen4-Max on 16 November: a 2.4-trillion-parameter flagship that it says cuts the average cost per professional task by 62%. Independent testing agrees the cost fell sharply — but at $3.27 per task it still costs more than Google's Gemini 4 Hydrogen, which scores eleven points higher.
